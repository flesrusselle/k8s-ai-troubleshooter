CRONJOB STATUS
──────────────────────────────────────────────────────────
{{- if .Values.cronJob.enabled }}
✅  CronJob is ENABLED.
    Schedule : {{ .Values.cronJob.schedule }}
    The collector will run automatically on this schedule.

    To watch job runs:
      kubectl get jobs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }} -w

    To view the latest run logs:
      kubectl logs -n {{ .Release.Namespace }} \
        $(kubectl get pod -n {{ .Release.Namespace }} \
          -l app.kubernetes.io/instance={{ .Release.Name }} \
          --sort-by=.metadata.creationTimestamp -o name | tail -1)
{{- else }}
⚠️  CronJob is DISABLED (cronJob.enabled=false).

    To enable it, upgrade the release with:
      helm upgrade {{ .Release.Name }} k8s-ai-troubleshooter \
        --set cronJob.enabled=true \
        --set cronJob.schedule="0 * * * *"

    To run a one-shot job immediately:
      kubectl create job --from=cronjob/{{ include "k8s-ai-troubleshooter.fullname" . }} \
        {{ include "k8s-ai-troubleshooter.fullname" . }}-manual \
        -n {{ .Release.Namespace }}
{{- end }}
