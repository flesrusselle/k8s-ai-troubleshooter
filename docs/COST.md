# Cost Model — $0 Total Cost

`k8s-ai-troubleshooter` is 100% free and open-source by design.

---

## 💰 No Paid Dependencies

* **No Paid AI APIs**: Does not require OpenAI, Claude, Gemini, or third-party AI keys.
* **No Paid Kubernetes Services**: Works with local `kind`, `minikube`, `k3d`, microk8s, or existing cluster access.
* **No Cloud / SaaS Dependencies**: Runs entirely local or inside free GitHub Actions workflows.
* **Zero Database / Hosting Fees**: Pure repository file-system knowledge base.

---

## ⚡ GitHub Actions Optimization

GitHub Actions workflows are optimized to use minimal runner minutes by utilizing lightweight Python validation scripts, cached environments, and focused checks.
